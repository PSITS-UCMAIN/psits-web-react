# Input Validation

## Accept

Natural language | GitHub issue | bullet points

## Required Info

Before plan, need:

1. **End state** — What = done?
2. **Constraints** — Must not break X? Ship by Y? Tech limits?
3. **Scope** — What out of scope? Deferred work?

## Proceed If

- All 3 areas clear
- Scope unambiguous
- Constraints explicit or obvious
- Outcome measurable

## Ask If

- End state vague/multiple meanings
- Critical constraints unknown
- Scope unclear
- Contradictory reqs

## How Ask

1. One focused question
2. Explain why need answer
3. Offer options when helpful
4. Be specific

**Good:**
"Migration preserve sessions or require re-login?"

**Bad:**
"What want?" | "More details?" | "Is this correct?"

## Rule

**Never plan on assumptions.** Wrong plan worse than no plan.

If missing critical info + can't infer from code/docs/conventions -> stop + ask.
